How to use the Custom Template System

If you want to use your own custom layout, you need to add special "anchor pixels" to your image. The system scans your template for these exact colors to know where to place the clothing.

Color Code

Place single 1x1 pixels of these exact RGB values on your template. Warning: Do not use these specific colors anywhere else in your image, or the clothing will duplicate.

  • 🔴 rgb(255, 0, 0) - Right Arm
  • 🟢 rgb(0, 255, 0) - Front Torso
  • 🔵 rgb(0, 0, 255) - Back Torso
  • 🟡 rgb(255, 255, 0) - Left Arm

Downloading

Because this tool runs entirely in your browser, the download won't start automatically. Simply Right-Click on the generated image and select "Save image as..." to download your showcase.
